# 艾宾浩斯复习助手

一个基于艾宾浩斯遗忘曲线的学习复习管理工具，专为公务员备考设计。

![version](https://img.shields.io/badge/version-v3.0-blue)
![platform](https://img.shields.io/badge/platform-Web-lightgrey)

## ✨ 功能特性

### 📚 分类管理
- **行测 / 申论** 两大类分别管理
- 行测细分为 5 个模块：政治理论、言语理解、数量关系、判断推理、资料分析
- 每个知识点标注分类和模块，一目了然

### 🔄 艾宾浩斯复习循环
- 每个知识点自动生成 7 次复习任务
- 复习节点：第 1 天、第 2 天、第 4 天、第 7 天、第 15 天、第 30 天、第 60 天
- 到期自动出现在"今日复习"列表

### 📊 数据统计
- 每日完成率统计
- 累计知识点和复习次数
- 7 天完成率柱状图
- 行测各模块学习占比
- 连续打卡天数

### 📅 日历视图
- 90 天日历总览
- 每天任务数量一目了然
- 点击任意日期查看当天任务

### 💾 本地数据存储
- 数据保存在浏览器本地，安全私密
- 支持导出/导入 JSON 备份
- 换设备、清缓存也不怕丢

### 📱 移动端友好
- 响应式设计，手机操作流畅
- 支持"添加到主屏幕"，像 App 一样使用

## 🚀 快速开始

### 在线访问
直接在浏览器中打开：
```
https://oaeeny.github.io/Ebinghaus/
```

### 添加到手机桌面（推荐）

**iOS（iPhone）：**
1. 用 Safari 打开上面的网址
2. 点底部分享按钮（方框+箭头）
3. 往下滑，点"添加到主屏幕"
4. 命名为"复习助手"，点添加
5. 桌面出现图标，点击即用

**Android：**
1. 用 Chrome 打开网址
2. 点右上角菜单（三个点）
3. 选"添加到主屏幕"或"安装应用"

## 📖 使用指南

### 添加知识点
1. 在"今日"页面，底部输入框填写知识点名称
2. 选择分类：行测 / 申论
3. 如果选了行测，再选择具体模块
4. 点"添加"按钮
5. 系统自动生成 7 次复习计划

### 每日复习
1. 打开 App，查看"今日复习"列表
2. 逐个复习，完成后点左边圆圈打勾
3. 新学的内容也在"今日新学"里打勾

### 查看计划
- 切换到"计划"页面，查看日历
- 点击任意日期，查看当天的学习和复习任务
- 可以按行测/申论筛选

### 数据备份
1. 切换到"设置"页面
2. 点"导出数据备份"，下载 JSON 文件
3. 换设备时，点"导入数据备份"，选择备份文件

## 📅 艾宾浩斯复习节点

| 复习次数 | 时间点 | 说明 |
|---------|--------|------|
| 第 1 次 | 学习当天 | 30分钟内回顾一次 |
| 第 2 次 | 第 2 天 | 隔夜后回顾 |
| 第 3 次 | 第 4 天 | 隔两天巩固 |
| 第 4 次 | 第 7 天 | 一周后强化 |
| 第 5 次 | 第 15 天 | 半个月后进入长期记忆 |
| 第 6 次 | 第 30 天 | 一个月后稳定记忆 |
| 第 7 次 | 第 60 天 | 两个月后基本不忘 |

## 💡 使用建议

### 公务员备考最佳实践
- **每天添加 3-5 个知识点**为宜，贪多嚼不烂
- **优先保证前 3 次复习**（当天、第2天、第7天），这三次最关键
- **通勤时间**用来刷复习内容，效果最好
- **错题也可以当知识点**录入，反复复习错题

### 各模块录入建议
| 模块 | 录入内容 |
|------|---------|
| 资料分析 | 公式、速算技巧、易错坑点 |
| 判断推理 | 图推规律、逻辑公式、类比关系 |
| 言语理解 | 成语辨析、实词搭配、主旨方法 |
| 数量关系 | 题型公式、秒杀技巧 |
| 政治理论 | 时政热点、重要会议、法律条文 |
| 申论 | 金句、案例、答题框架 |
